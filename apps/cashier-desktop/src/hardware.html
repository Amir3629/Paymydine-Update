Optional native hardware setup for this PayMyDine computer.

Print output

Use a real receipt printer at the restaurant, or Virtual PDF when testing without hardware.

No physical printer is used. Print jobs are saved as PDF in Desktop / PayMyDine Print Tests. Cash drawer commands are disabled in this mode.
Print receipt automatically after payment
When the Platform opens a receipt after a successful payment, PayMyDine Desktop can send it to this output.

Cash drawer

PayMyDine sends an ESC/POS kick through the selected receipt printer. Virtual PDF mode never touches drawer hardware.

Open automatically after cash payment
Only a successful server-confirmed Cash payment can trigger this. Card payments never open the drawer.
