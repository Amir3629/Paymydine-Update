PayMyDine Frontend V2 — Integrated QR Menu Release
Release: 1.1.0-staging.20260815-integrated

PRODUCT CONTRACT
================
This is a dine-in QR table menu. Customer-facing Phone / Call-to-Order and Table Note UI are removed from all ten themes and shared runtime. Backend compatibility data/routes may remain, but V2 does not render or call them.

CONNECTED
=========
- Ten isolated themes, selected server-side.
- New V2-only backend theme endpoint: /api/v2/frontend-theme.
- Ten-theme Admin selector and V2 feature switches.
- Existing menu, table/QR, shared table order, kitchen submit, waiter, valet, VAT, tips, coupons, payment and split-bill contracts.
- Tenant-aware backend origin resolution; no dependency on a local Laravel :8000 listener.
- Asset/media normalization for staging and production tenant hosts.

SECURITY / INSTALL
==================
Next is pinned to 16.3.1. The source ZIP intentionally omits the stale pre-fix lockfile. Run:

  cp .env.example .env.local
  npm run secure:install
  npm run release:audit
  npm run build

secure:install generates a fresh lockfile and runs npm audit repair without --force.

ADMIN BRIDGE
============
Install only after reviewing the backup path:

  sudo env PMD_ROOT=/var/www/paymydine bash integration/laravel/install-v2-theme-bridge.sh

The installer backs up live files and does not modify legacy /simple-theme, port 3001, Nginx or the database.

PRODUCTION SAFETY
=================
Keep the current customer frontend on port 3001 until real QR, two-device order, second-order, waiter/valet, payment and paid-state synchronization QA passes on port 3002.
