# Build Fix - 2026-08-15

This release corrects the issues found by the first real `npm ci` / `next build` run on macOS.

## Fixed

1. **Next.js 16 route-handler type error**
   - Replaced `NextRequest` / `NextResponse` in local API handlers with the Web `Request` / `Response` contract.
   - Added explicit `Response` return types for the bootstrap, health and locale handlers.
   - The locale cookie is now emitted with a standard `Set-Cookie` header.

2. **Turbopack workspace-root warning**
   - `next.config.mjs` pins `turbopack.root` to this project directory so a lockfile in a parent Downloads folder is not selected as the application root.

3. **Next.js tsconfig auto-rewrite**
   - `jsx` is pre-set to `react-jsx`.
   - `.next/dev/types/**/*.ts` is included explicitly.

4. **Release audit false positive after installation**
   - `node_modules`, `.next`, and local environment files are expected in an installed working copy and are ignored by the working-copy audit.
   - They remain excluded from source packaging by `.gitignore` and are not part of the release ZIP.

## Correct validation order

```bash
cp .env.example .env.local
npm ci
npm run release:audit
npm run build
```

Do not deploy to port 3001. Validate on port 3002 first.
