# ZCS vendor SDK

For ZCS customer-display hardware builds, place the vendor-supplied file here:

`SmartPos_2.0.6_R260615.aar`

Expected SHA-256:

`fe2269746167064571ae23fc655838f203436deeb145606ff5c2d34b0054db18`

The binary is proprietary vendor material and is intentionally not committed to this repository.

Without the AAR the Android app still compiles; the customer-display hardware adapter stays unavailable at runtime.
